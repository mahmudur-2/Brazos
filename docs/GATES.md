# GATES — phase gates

A box is ticked only with the evidence path beside it (file, test name, HANDOFF line). Never from a plan, a prompt, or memory. Order is the rule: nothing in a later gate starts while an earlier gate has an open box.

An OPEN box carries what the repository DOES prove and what is still missing, so the
next run reads the gap instead of re-deriving it. A partly-proven box is open: every
clause has to hold.
